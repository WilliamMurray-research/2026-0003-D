## 1. System Overview & Spatial Hierarchy

The Hierarchical Reinforcement Learning (HRL) platform optimizes spatial water management and climate‑adaptation interventions across complex deltaic systems. It operates across a two‑tier spatial and temporal hierarchy, decoupling macro‑level hydrological allocation from micro‑level physical execution.

```
┌─────────────────────────────────────────────────────────────────────────┐
│                       MACRO-AGENT (Sub-Basin Scale)                     │
│  • Spatial Bounds: 200 x 300 Grid (1 km² Resolution)                    │
│  • Time Horizon: 5–10 Years (Seasonal Steps)                            │
│  • Core Task: Continuous Inter-Basin Water Allocation Vectors (b_k)     │
└────────────────────────────────────┬────────────────────────────────────┘
                                     │
                  Passes Target Boundary Vectors (b_k)
                                     │
                                     ▼
┌─────────────────────────────────────────────────────────────────────────┐
│                      MICRO-AGENT (Reach / Plot Scale)                   │
│  • Spatial Bounds: 100 x 100 Grid (100 m² Resolution)                   │
│  • Time Horizon: 1 Year (Monthly Steps)                                 │
│  • Core Task: Discrete Physical Placement & Local Governance Actions    │
└─────────────────────────────────────────────────────────────────────────┘
```

## 2. Mathematical Formulation & Composite Reward Function

The scalar reward **R(s, a, s′)** is a multi‑objective linear combination of hydrological, governance, ecological, economic, and risk‑penalty terms.

### 2.1 Reward Components

- **Seasonal HydroECA Gain (R_hydro)**  
- **Governance Feasibility Exploration Bonus (R_GFI)**  
  - Weighted by counterfactual connectivity yield ΔHydroECA\*  
- **Salinity Intrusion Penalty (P_salinity)**  
  - Threshold: 2.0 ppt for paddy rice  
- **Community Co‑Benefits Bonus (B_community)**  
  - Crop yield ΔYᵤ, fisheries ΔFᵤ, employment Eᵤ  
- **Implementation Cost (C(s, a))**  
  - Severe penalty during monsoon construction windows  
- **Morphodynamic Volatility Penalty (P_morph)**  
  - Risk‑aversion coefficient μₑᵣₒₛᵢₒₙ

## 5. Fail‑Safes & Human‑in‑the‑Loop Protocols

Risk monitoring uses Channel 13 (σᵐᵒʳᵖʰ) and Channel 8 (GFI).

### 5.1 Risk Escalation Matrix

```
STAGE 1 — YELLOW ALERT
Trigger: σ ∈ [0.65, 0.85) OR GFI ∈ (0.25, 0.40]
Action: 3× w_morph penalty; 72‑hr field audit

STAGE 2 — RED ALERT
Trigger: σ ≥ 0.85 OR GFI ≤ 0.25
Action: Physical actions masked; 24–48 hr HITL review
```

### 5.2 Automated Action Masking

- Node capacity αᵤ = 0  
- Capital reallocated to secondary nodes  
- MCTS topology re‑routed automatically

## 6. Phase D Field Validation Protocol

24‑month deployment across **16 coastal Union Parishads** (8 treatment, 8 control), separated by a 5 km buffer.

```
PRE‑INTERVENTION (Months −6 to 0)
• Baseline Metrics
• Synthetic Control Weighting (W*)
• Parallel Trends Verification (p < 0.01)

POST‑INTERVENTION (Months 1 to 24)
• HRL Intervention Execution
• Monthly / Quarterly Audits
• Difference‑in‑Differences Evaluation
```

### 6.1 Synthetic Control & DiD

- Construct synthetic control i\* using optimal donor weights W\*  
- Dynamic treatment effect estimation  

### 6.2 Phase D Exit Gates (for Phase E Rollout)

Must satisfy all four:

1. **HydroECA Gain:** ≥ 18% above synthetic control (p < 0.01)  
2. **Model Accuracy:** RMSE < 12%  
3. **Governance Pipeline Health:** No cell stuck in exploration > 9 months  
4. **Salinity Mitigation:** ≥ 2.5 dS/m reduction in dry‑season peak salinity
