## Abstract
Self‑managed organisations must translate collective intent into a tangible distribution of surplus without re‑introducing managerial discretion. We present a rule‑based, peer‑validated engine that (i) codifies the constitutional consent principle from our preceding work on governance, (ii) measures contribution in an entropy‑adjusted way derived from the Entropy‑Adjusted Productivity (EAP) framework, and (iii) guarantees low‑entropy, manipulation‑resistant distribution through robust estimators, peer‑pool rotation, and a constitutionally defined conflict‑resolution process. The engine implements the 23% profit‑share that emerged in Semler’s *Maverick* as a democratic decision; it can be altered by the same voting mechanism. The resulting model is mathematically rigorous yet operationally simple, making it suitable for real‑world deployment.  

**Keywords:** constitutional governance, entropy-adjusted productivity, peer validation, surplus distribution, self-management, statistical calculus

## 1 – Introduction
The paradox of self-managed work forces organisations to find a way to allocate the residual value they create while preserving autonomy and avoiding hierarchical voting. Traditional performance metrics (output per hour, KPIs) do not map onto the entropy that truly defines value in knowledge-intensive settings. This paper introduces Constitutional Statistical Calculus (CSC) – an engine that translates peer-observed indicators into a deterministic surplus distribution while respecting constitutional consent and maintaining low entropy.  

We build on two theoretical pillars:  

1.  The constitutional governance framework of Murray (2026), which argues that legitimate authority is derived from explicit, ratified constraints rather than rank;  
2.  The Entropy-Adjusted Productivity (EAP) framework (Edwards & Dempsey, 2025; Murray, 2025), which shows that organisational value equals the reduction in entropy per unit of cognitive energy.  

CSC operationalises both: it uses constitutional consent to fix the surplus slice and to ratify domain weight coefficients, and it applies EAP’s notion of entropy-adjusted contribution to define peer-observed indicators.  

## 2 – Theoretical Foundations  
### 2.1 Constitutional Governance  
Our earlier work posits that organisational authority should be domain-bounded rather than rank-based: each contributor is given a set of decision rights determined by the domain in which they operate, and those rights are protected by explicit constitutional instruments (Murray, 2026). This principle extends to surplus distribution: no single individual may alter another’s share; all rules are codified in the constitution.  

### 2.2 Entropy-Adjusted Productivity (EAP)  
EAP reframes productivity as entropy reduction per unit of cognitive energy. The key insight is that value is produced when a contributor reduces organisational equivocality while expending their attention. Therefore, indicators of value should capture the amount by which a member’s work collapses uncertainty, not merely the quantity of output.  

## 3 – Formal Model  
### 3.1 Contributor Set and Domains  
Let $C = \{1, 2, \dots, n\}$ be the set of active contributors. Each member $i \in C$ is evaluated across three constitutionally defined contribution domains:  

| Domain | Symbol | Domain Name | Operational Meaning |
| :--- | :--- | :--- | :--- |
| $C$ | $C_i$ | Capability Contribution | Execution reliability, output quality, and feature/deliverable completion. |
| $K$ | $K_i$ | Community Engagement | Cross-team collaboration, mentorship, knowledge sharing, and governance. |
| $V$ | $V_i$ | Value (Entropy Reduction) | Degree to which work resolves organizational ambiguity, simplifies systems, or unblocks critical paths. |

Define the raw contribution vector for member $i$ as:  

$$c_i = (C_i, K_i, V_i)$$  

### 3.2 Peer Observation Sets  
For each domain $d \in \{C, K, V\}$, member $i$ receives an observation set $X_{i,d}$ from $m_i$ randomly assigned peers:  

$$X_{i,d} = \{ x^{(1)}_{i,d}, x^{(2)}_{i,d}, \dots, x^{(m_i)}_{i,d} \}$$  

where $0 \le x^{(k)}_{i,d} \le 1$ and $m_i \ge 5$.

To reduce subjectivity in $V_i$, observations must be evaluated against standardized, constitutionally defined rubrics describing discrete levels of ambiguity reduction.  

### 3.3 Robust Constitutive Estimator
To ensure high breakdown resistance against extreme scores or outlier bias, the domain score $\hat{d}_i$ is calculated via the median:  

$$\hat{d}_i = \text{median}( X_{i,d} ) \quad \text{for all } d \in \{C, K, V\}$$  

The median is low-entropy, highly robust to non-systemic collusion, and satisfies:  

$$\left[ \frac{\partial \hat{d}_i}{\partial x^{(k)}_{i,d}} \right] \le \varepsilon \quad \text{for all non-median points } x^{(k)}_{i,d}$$  

### 3.4 Anti-Gaming Safeguard: Peer-Pool Rotation
To disrupt long-term reciprocity rings, the peer observation set for each contributor is reshuffled every $R$ months:  

$$X_{\text{new},i,d} \leftarrow \text{RandomPick}( P_d \setminus \{i\}, m_i )$$  

where $P_d \subseteq C$ is the full pool of eligible peers for domain $d$.  

### 3.5 Inter-Observer Variance & Anomalous Score Auditing
Let the sample variance of observations for contributor $i$ in domain $d$ be:  

$$\sigma^2_{i,d} = \text{Var}( X_{i,d} )$$  

If $\sigma^2_{i,d} > \sigma^2_{\max}$ (where $\sigma^2_{\max}$ is a constitutionally set threshold), the observation set is flagged as anomalous. Rather than applying a punitive automated deduction—which could be weaponized by polarising peer groups—a variance flag triggers an automatic review by the Protector Body (§6.3) to investigate potential collusion or malicious scoring while leaving $\hat{d}_i$ intact pending review.  

### 3.6 Weight Function and Individual Score
Each contribution domain receives a constitutional weight ratified by the organization:  

$$\alpha_C, \alpha_K, \alpha_V \ge 0 \quad \text{such that } \alpha_C + \alpha_K + \alpha_V = 1$$  

The composite contribution score $w_i$ for member $i$ is calculated as:  

$$w_i = (\alpha_C \cdot \hat{C}_i) + (\alpha_K \cdot \hat{K}_i) + (\alpha_V \cdot \hat{V}_i)$$  

*Note: The weights $\alpha_d$ are ratified by simple majority vote at the start of each fiscal year and apply globally across $C$.*  

### 3.7 Surplus Distribution Engine
Let $S$ denote the total organizational surplus for the period, and $SEVF$ denote the designated surplus pool:  

$$SEVF = 0.23 \cdot S$$  

Each contributor’s final allocated dividend $D_i$ is determined by:  

$$D_i = p_i \cdot SEVF \cdot \left[ \frac{w_i}{\sum_{j \in C} (p_j \cdot w_j)} \right] \quad (\text{Equation 3.7})$$  

where $p_i \in \{0, 1\}$ is the participation flag (§5). Equation (3.7) represents a fully deterministic, rule-based engine: once peer median scores and democratic weights are set, allocations execute automatically without managerial intervention.  

## 4 – Justification of the 23% Rule  

| Source | Argument |
| :--- | :--- |
| Semler’s *Maverick* & The Seven Day Weekend | The 23% profit-share proportion was originally adopted through a democratic vote of all employees; it reflects collective consent rather than managerial discretion. |
| Constitutional Principle | The surplus percentage is a parameter ratified by the community. It can be adjusted for future fiscal cycles through an explicit majority vote (e.g., 70% threshold). |

## 5 – Participation Sovereignty  

Each member holds individual sovereignty over their participation in the surplus distribution pool for any given cycle:  

$$p_i = \begin{cases} 1 & (\text{if member elects to participate in the period}) \\ 0 & (\text{otherwise}) \end{cases}$$  

Voluntary withdrawal or re-entry toggles $p_i$ without affecting historical allocations, preserving past equity while respecting ongoing personal consent.  

## 6 – Conflict Resolution & Protector Arbitration  

### 6.1 Constitutional Constraint Set
Define the valid state space for domain estimators and weights as:  

$$\Omega_{\text{const}} = \{ (\hat{C}, \hat{K}, \hat{V}, \alpha) \mid 0 \le \hat{C}_i, \hat{K}_i, \hat{V}_i \le 1 \quad \forall i; \alpha_d \ge 0, \sum \alpha_d = 1 \}$$  

### 6.2 Conflict Detection
A system flag is raised if:  

*   Any estimator $\hat{d}_i$ falls outside valid boundaries $[0, 1]$;  
*   Sample variance exceeds safety bounds ($\sigma^2_{i,d} > \sigma^2_{\max}$);  
*   An explicit non-consent dispute is lodged by a contributor regarding procedural irregularities in peer rotation.  

### 6.3 Protector Arbitration Process  
**Protector Body Selection:** An elected, non-managerial committee of peers reviews the system flags.  
**Investigation:** The committee examines anonymized peer scoring distributions $X_{i,d}$.  
**Resolution:** The committee may throw out corrupt peer inputs, request a new randomized peer sample, or confirm the calculated median. Any adjusted estimator $\hat{d}'_i$ must lie within $\Omega_{\text{const}}$.  

## 7 – Implementation Considerations  
*   **Data Collection & Tooling:** Peer scoring must be collected via an anonymized tool that computes medians and variance server-side to avoid interpersonal friction.  
*   **Auditability & Transparency:** Calculated medians $\hat{d}_i$, weight coefficients $\alpha_d$, and the final distribution vector $D$ must be published to all members at the close of each cycle.  
*   **Survey Fatigue Mitigation:** Restricting peer sample sizes to $m_i \in [5, 8]$ prevents feedback fatigue while maintaining the statistical integrity of the median estimator.  

## 8 – Conclusion  
CSC operationalises constitutional consent and entropy-adjusted value in a single, transparent engine. By using peer-validated median estimates, rotating peer pools, and constitutionally defined conflict resolution, it preserves autonomy while eliminating managerial discretion. The 23% surplus slice is an explicit democratic decision; the weight coefficients are similarly ratified each fiscal year. This design offers a ready-to-implement framework for any self-managed organisation that wishes to translate collective intent into fair, low-entropy distribution of surplus.

## Appendix A – Proof that Median Minimises Expected Absolute Deviation  

Let $X = \{x_1, \dots, x_m\}$ be i.i.d. observations with distribution $F(x)$. The expected absolute deviation from an estimator $\theta$ is:  

$$E[ | X - \theta | ] = \int | x - \theta | dF(x)$$  

Taking the derivative with respect to $\theta$:  

$$\frac{d}{d_\theta} E[ | X - \theta | ] = -P( X > \theta ) + P( X < \theta )$$  

Setting the derivative to zero yields:  

$$P( X < \theta ) = P( X > \theta )$$  

which defines $\theta$ as a median of $F(x)$. Hence, the median minimizes expected absolute deviation, providing maximum statistical robustness for the estimator.
